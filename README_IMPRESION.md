# 🌿 Guía de Plantas Medicinales - Archivos de Impresión

Este paquete contiene toda la información sobre **26 plantas medicinales y hongos** en formatos listos para usar.

## 📦 Archivos Incluidos

### 1. **PLANTAS_MEDICINALES_PDF.html** - Guía Completa para PDF
**Descripción:** Documento HTML profesional listo para imprimir o convertir a PDF

**Contenido:**
- Portada elegante
- 26 fichas detalladas por especie
- Tabla resumen completa
- Guía de preparación de tinturas
- Conversiones y equivalencias
- Formato optimizado para impresión A4

**Cómo usar:**
1. Abrir el archivo `.html` en cualquier navegador web (Chrome, Firefox, Safari)
2. Presionar `Ctrl+P` (Windows) o `Cmd+P` (Mac)
3. Seleccionar:
   - Destino: **"Guardar como PDF"** o **"Imprimir a PDF"**
   - Papel: A4
   - Márgenes: Predeterminados
   - Escala: 100%
4. Guardar el PDF generado

**Resultado:** ~15-20 páginas de guía profesional completa

### 2. **ETIQUETAS_TINTURAS.html** - Etiquetas Minimalistas
**Descripción:** 26 etiquetas (6×4cm) + 6 en blanco para imprimir y pegar en frascos

**Contenido:**
- Etiquetas minimalistas con:
  - Número de referencia
  - Nombre común (MAYÚSCULAS)
  - Nombre científico (cursiva)
  - Ícono decorativo
- Código de colores:
  - Verde/Blanco: Seguro y legal
  - Naranja: Regulado/Precaución
  - Rojo: Peligroso/Ilegal
- Página de instrucciones (no se imprime)
- 6 etiquetas en blanco personalizables

**Cómo imprimir:**

#### Opción 1: Papel Adhesivo (Recomendado)
1. Comprar papel adhesivo mate A4 (para tinturas: mejor mate que brillante)
2. Configurar impresora:
   - Papel: A4
   - Márgenes: 1cm todos los lados
   - Escala: 100% (NO ajustar)
   - Calidad: Alta (600 DPI mínimo)
3. Imprimir
4. Recortar con tijera o cutter siguiendo los bordes
5. Opcional: Plastificar con cinta transparente (mayor durabilidad)

#### Opción 2: Papel Normal + Cinta Adhesiva
1. Imprimir en papel normal
2. Recortar etiquetas
3. Plastificar con cinta adhesiva transparente por ambos lados
4. Pegar con cinta adhesiva de doble cara o masking tape

#### Opción 3: Papel Kraft Adhesivo (Look Vintage)
Mismo proceso que Opción 1, pero con papel kraft color marrón para estética natural/artesanal

**Materiales sugeridos:**
- ✅ Papel adhesivo mate: Avery, Apli, Printec
- ✅ Cutter + regla metálica (cortes rectos profesionales)
- ✅ Cinta adhesiva transparente (ancho 5cm para plastificar)

**Resultado:** 26-32 etiquetas profesionales para tus frascos de tintura

## 🆕 Nuevas Plantas Agregadas (Versión 2.0)

### #25: Ginkgo biloba
- **Usos:** Memoria, circulación cerebral, vértigo, tinnitus
- **Dosis tintura:** 30-60 gotas × 2-3/día
- **Extracto:** 120-240mg/día (estandarizado)
- **⚠️ Importante:** Anticoagulante leve - suspender 2 semanas antes de cirugía

### #26: Ashwagandha (Withania somnifera)
- **Usos:** Adaptógeno, reduce cortisol (-30%), estrés, ansiedad, energía
- **Dosis tintura:** 2-4ml × 2/día
- **Extracto:** 300-600mg/día (5% withanólidos)
- **⚠️ Importante:** Puede aumentar hormonas tiroideas (no usar en hipertiroidismo)

## 📝 Recomendaciones de Impresión

### Para encuadernar la guía completa:
1. Imprimir `PLANTAS_MEDICINALES_PDF.html` → PDF
2. Opciones de encuadernación:
   - Anillado (más práctico para consultar)
   - Grapado (económico)
   - Carpeta de 3 anillos (permite agregar hojas)

### Para organizar tinturas:
1. Imprimir `ETIQUETAS_TINTURAS.html` en papel adhesivo
2. Etiquetar cada frasco con:
   - Etiqueta frontal minimalista
   - Etiqueta trasera con fecha de elaboración y notas (escribir a mano)
3. Organizar por número o categoría:
   - #1-10: Regulados/Especiales
   - #11-24: Medicinales comunes
   - #25-26: Nootrópicos/Adaptógenos

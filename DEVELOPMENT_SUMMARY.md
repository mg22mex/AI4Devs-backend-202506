### 🔧 Technical Decisions

#### Why React?
- Component-based architecture for reusability
- Fast rendering with Virtual DOM
- Large ecosystem and community
- Easy state management for calculators

#### Why Pure CSS?
- No external CSS framework needed
- Full control over styling
- Better performance (no unused CSS)
- Modern CSS3 features (gradients, animations, flexbox, grid)

#### Why JavaScript over TypeScript?
- Faster development for MVP
- Simpler setup for single-page app
- Easier for community contributions
- Can migrate to TypeScript later if needed

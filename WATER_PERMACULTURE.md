## Curvas de Nivel y Topografía

### Introducción

Las **curvas de nivel** (o contour lines) son líneas imaginarias que conectan puntos de igual elevación en un terreno. Son la base del diseño permacultural y la gestión regenerativa del agua.

### Importancia Crítica

1. **Prevención de Erosión**: El 70% de la erosión del suelo se debe a agua de escorrentía sin control
2. **Infiltración de Agua**: Terrenos diseñados con curvas pueden infiltrar 10-20 veces más agua
3. **Recarga de Napas**: Sistemas de swales recargan acuíferos subterráneos
4. **Ubicación Óptima**: Estructuras, caminos y cultivos se ubican según topografía
5. **Eficiencia Hídrica**: Cada litro de lluvia trabaja múltiples veces antes de salir del sistema

### ¿Qué es una Curva de Nivel?

> Una línea que conecta todos los puntos que están a la misma altura sobre el nivel del mar.

**Analogía**: Es como la línea de la orilla del mar cuando la marea sube. Si el mar subiera 1 metro, la nueva línea de la orilla sería otra curva de nivel.

### Herramientas de Levantamiento Topográfico

#### 1. Nivel A (A-Frame) - DIY y Gratis
```
Construcción:
- 2 palos de 2m formando una "A"
- 1 palo horizontal de 1m (travesaño)
- 1 cuerda con plomada colgando del vértice
- Marcas en el travesaño (centro)

Uso:
- Caminar en contorno del terreno
- Cuando plomada marca centro = mismo nivel
- Marcar con estacas cada 5-10m
- Unir estacas = curva de nivel
```

**Precisión**: ±5cm cada 10m (suficiente para swales)  
**Costo**: $0-$5,000 CLP (materiales reciclados)

#### 2. Nivel Láser de Constructor
- **Uso**: Terrenos pequeños (hasta 1 hectárea)
- **Precisión**: ±2mm cada 10m
- **Costo**: $80,000-$200,000 CLP
- **Velocidad**: 5x más rápido que nivel A

#### 3. GPS Diferencial (DGPS)
- **Uso**: Terrenos grandes (5+ hectáreas)
- **Precisión**: ±1cm
- **Costo Servicio**: $150,000-$400,000 CLP por hectárea
- **Resultado**: Plano digital CAD con curvas cada 0.5-1m

#### 4. Drones con LiDAR (Profesional)
- **Uso**: Terrenos muy grandes o complejos
- **Precisión**: ±5cm
- **Costo**: $500,000-$1,500,000 CLP por proyecto
- **Ventaja**: Modelo 3D completo del terreno

### Interpretación de Curvas de Nivel

#### Espaciamiento de Curvas
```
Curvas muy juntas = PENDIENTE PRONUNCIADA
   |  |  |  |  |
   |  |  |  |  |  Pendiente 20-30%+
   |  |  |  |  |

Curvas separadas = PENDIENTE SUAVE
   |        |        |
   |        |        |  Pendiente 5-10%
   |        |        |

Curvas muy separadas = CASI PLANO
   |                      |
   |                      |  Pendiente 0-3%
   |                      |
```

#### Formas del Terreno

**Valle (agua converge)**:
```
    \  |  /
     \ | /    ← Las curvas apuntan "hacia arriba"
      \|/     → Agua se acumula aquí
       V      → Ideal para estanques
```

**Cresta/Loma (agua diverge)**:
```
       ^
      /|\     ← Las curvas apuntan "hacia abajo"
     / | \    → Agua sale desde aquí
    /  |  \   → Línea divisoria de aguas
```

### Diseño de Swales en Curvas de Nivel

#### ¿Qué es un Swale?

> Un swale es una zanja poco profunda construida exactamente siguiendo una curva de nivel (sin pendiente), con una berma/loma en el lado bajo, diseñada para capturar y infiltrar agua de lluvia.

**NO es**:
- ❌ Canal de drenaje (que tiene pendiente)
- ❌ Zanja de fundación
- ❌ Acequia de riego

**ES**:
- ✅ Sistema de infiltración
- ✅ Recarga de napas
- ✅ Prevención de erosión
- ✅ Hidratación de paisaje

#### Dimensiones Típicas de Swales

**Para terreno residencial (1-5 hectáreas):**
```
Vista de Corte del Swale:
                    ← Lado Alto (hacia cerro)
    _______________
   /               \____  ← Berma plantada
  /  30-50cm prof   \    \
 |____________________|   \
 ↑                    ↑    ↑
 50-80cm ancho     Fondo   Berma
                   plano   30-40cm
```

**Especificaciones por Pendiente:**

| Pendiente | Ancho Swale | Profundidad | Distancia entre Swales |
|-----------|-------------|-------------|------------------------|
| 0-3%      | 50-60cm     | 30cm        | 40-60m                 |
| 3-8%      | 60-80cm     | 40cm        | 25-35m                 |
| 8-15%     | 80-100cm    | 50cm        | 15-25m                 |
| 15-25%    | 100-120cm   | 50-60cm     | 10-15m                 |
| 25%+      | Terrazas    | 60cm+       | 8-12m                  |

#### Proceso de Construcción de Swales

**Paso 1: Marcación con Nivel A (2-3 días)**
1. Empezar desde parte alta del terreno
2. Usar nivel A para encontrar contorno
3. Marcar cada 3-5m con estaca
4. Verificar con manguera de nivel (transparente con agua)
5. Ajustar estacas hasta línea perfecta horizontal

**Paso 2: Excavación (1-2 días por 30m)**
1. **Manual** (pala y picota):
   - Velocidad: 5-8 metros lineales/día/persona
   - Ideal: pendientes fuertes, cerca de árboles
   - Costo: $15,000-$25,000 CLP/metro lineal

2. **Retroexcavadora** (más común):
   - Velocidad: 50-80 metros lineales/día
   - Ideal: terrenos abiertos, pendiente 3-15%
   - Costo: $8,000-$15,000 CLP/metro lineal
   - **Requiere operador experimentado** (mantener nivel)

**Paso 3: Formación de Berma**
- Tierra excavada se apila en lado BAJO del swale
- Compactar ligeramente (no demasiado)
- Forma suave, no angular (erosión)
- Altura: 30-50cm sobre terreno original

**Paso 4: Acabados**
- Fondo del swale: plano y parejo
- Profundidad uniforme en todo el largo
- Verificar con nivel: CERO pendiente
- Suavizar bordes y berma

**Paso 5: Reboses/Derrames**
```
Cada swale necesita un punto de desborde controlado:

Swale superior: ═══════════╗
                           ╚══> Desborde
                              ↓
Swale medio:    ═══════════╗
                           ╚══> Desborde
                              ↓
Swale inferior: ═══════════╝
```

- **Ubicación**: Cada 30-50m en swales largos
- **Diseño**: Suave depresión empastada (no canal)
- **Función**: Evitar ruptura de berma en lluvias extremas
- **Lleva agua**: Al siguiente swale o zona de infiltración

### Plantación de Bermas

La berma NO es solo tierra apilada - es un **sistema de raíces que captura agua**.

#### Diseño de Plantación en Berma

```
Vista superior de berma plantada:

Árbol  Arbusto  Árbol  Arbusto  Árbol
  🌳     🌿      🌳     🌿      🌳
═══════════════════════════════════  ← Swale
↑      ↑       ↑      ↑       ↑
3-4m  1.5m    3-4m   1.5m    3-4m
```

#### Especies Recomendadas para Bermas (Chile)

**Árboles Frutales** (Copa alta, raíces profundas):
- Manzanos (resistentes a humedad)
- Ciruelos (crecimiento rápido)
- Perales (raíces profundas)
- Nogales (raíz pivotante 6m+)
- Avellanos (fijadores de nitrógeno)

**Arbustos** (Copa baja, raíces densas):
- Zarzamora (biomasa masiva)
- Frambuesa (cobertura rápida)
- Sauco (medicinal + forrajero)
- Rosa mosqueta (vitamina C)
- Lavanda (aromática + polinizadores)

**Plantas de Cobertura** (Piso bajo, protección):
- Trébol blanco (fijador nitrógeno)
- Alfalfa (raíz hasta 4m prof)
- Consuelda (acumuladora nutrientes)
- Nasturtium (comestible + control plagas)

#### Cronograma de Plantación

**Año 1** (recién construido swale):
- Plantar solo hierbas y coberturas
- Dejar que el suelo se asiente
- Observar flujos de agua en temporada lluvias

**Año 2**:
- Plantar arbustos en berma
- Árboles pioneros de crecimiento rápido
- Mantener cobertura herbácea

**Año 3+**:
- Plantar árboles frutales definitivos
- Sistema ya estable y probado
- Producción comienza año 4-5

### Cálculo de Capacidad de Infiltración

#### Fórmula de Captura

```
Volumen capturado por swale:
V = L × W × D
Donde:
L = Largo del swale (metros)
W = Ancho del swale (metros)
D = Profundidad (metros)

Ejemplo: 100m × 0.6m × 0.4m = 24 m³ = 24,000 litros
```

#### Agua de Escorrentía Capturada

```
Área de captación sobre el swale:
A = L × D_entre_swales

Agua de lluvia capturada:
Q = A × P × C

Donde:
P = Precipitación (mm o m)
C = Coeficiente escorrentía (0.6-0.8 en pendiente)

Ejemplo terreno 1 hectárea con 600mm lluvia anual:
- Swales cada 20m en pendiente 8%
- 5 swales de 100m c/u
- Captación: 10,000 m² × 0.6m × 0.6 × 0.7 = 2,520 m³/año
  = 2,520,000 litros infiltrados (vs. perdidos por erosión)
```

### Mantenimiento de Swales

#### Mantenimiento Anual (esencial)

**Después de primeras lluvias (otoño):**
1. Inspeccionar toda la longitud
2. Reparar erosiones en berma
3. Remover sedimentos acumulados (si hay)
4. Verificar reboses funcionan bien

**Antes de temporada seca (primavera):**
1. Podar plantas de berma (mulch → swale)
2. Agregar materia orgánica si swale está vacío
3. Verificar que no haya obstrucciones

**Mantenimiento total:** 2-4 horas por cada 100m de swale/año

#### Problemas Comunes y Soluciones

| Problema | Causa | Solución |
|----------|-------|----------|
| Swale se llena de sedimento | Erosión aguas arriba | Plantar más cobertura arriba, limpiar swale |
| Berma se erosiona | Falta de plantas, lluvias fuertes | Replantar inmediato, suavizar pendiente berma |
| Agua se estanca (no infiltra) | Suelo muy arcilloso | Agregar materia orgánica, hacer grietas |
| Swale tiene pendiente (acumula agua) | Mal marcado o excavado | Re-nivelar tramos con pendiente |
| Plantas en berma mueren | Plantación muy temprana | Esperar 1 año asentamiento, elegir especies duras |

### Tipos Especiales de Swales

#### 1. Swale Infiltración Rápida
- **Uso**: Suelos arcillosos donde agua se estanca
- **Diseño**: Fondo con piedra drenante (10-15cm)
- **Costo adicional**: +30%
- **Resultado**: Infiltración 5x más rápida

#### 2. Swale Forestación
- **Uso**: Reforestar laderas degradadas
- **Diseño**: Más anchos (1.2-1.5m), más separados (30-50m)
- **Plantación**: Solo árboles nativos en berma
- **Objetivo**: Recrear bosque nativo funcional

#### 3. Swale Urbano/Periurbano
- **Uso**: Patios, huertos urbanos
- **Diseño**: Miniatura (30cm ancho × 20cm prof)
- **Construcción**: Manual, en 1-2 días
- **Ideal**: Pendientes 5-12% en terrenos 200-1000m²

## Cosecha de Agua de Lluvia

### Introducción

La **cosecha de agua de lluvia** captura, desvía y almacena agua de superficies impermeables (techos) para uso posterior.

**Diferencia con swales**: 
- Swales infiltran in-situ
- Cosecha almacena para uso

### Potencial de Captura de Agua

#### Fórmula Básica
```
Q = A × P × C × E

Donde:
Q = Agua cosechada (litros)
A = Área de captación (m²)
P = Precipitación (mm → m)
C = Coeficiente escorrentía (0.8-0.95 para techos)
E = Eficiencia sistema (0.85-0.95)

Ejemplo casa 100m² techo, 600mm lluvia anual:
Q = 100 × 0.6 × 0.9 × 0.9 = 48.6 m³ = 48,600 litros/año

Familia promedio usa ~200 litros/día = 73,000 L/año
→ Esta casa puede cubrir 67% de agua con lluvia
```

### Componentes del Sistema

#### 1. Superficie de Captación (Techo)

**Mejores materiales:**
- **Zinc/metal**: Eficiencia 95%, dura 30+ años
- **Tejas cerámicas**: Eficiencia 85%, necesita limpieza
- **Policarbonato**: Eficiencia 90%, liviano
- **Pizarra**: Eficiencia 80%, hermoso pero caro

**Evitar:**
- Asbestos/asbesto (contaminante)
- Techos con plomo en pintura
- Materiales porosos (pierden agua)

#### 2. Canaletas (Gutters)

**Dimensionamiento**:
```
Techo 50m² → Canaleta 4" (100mm)
Techo 100m² → Canaleta 5" (125mm)
Techo 200m² → Canaleta 6" (150mm)
```

**Pendiente**: Mínimo 0.5% (0.5cm cada metro) hacia bajadas

**Material**:
- PVC (barato, fácil instalación): $3,000-$5,000/metro
- Zinc (durable): $8,000-$12,000/metro
- Cobre (premium, 50+ años): $25,000-$40,000/metro

#### 3. Pre-Filtros (Crítico)

**First Flush Diverter** (Desviador Primera Lluvia):
```
   ┌─ Desde techo
   │
   ├─→ Primeros 20-30L → Descarte
   │   (polvo, hojas, excremento)
   │
   └─→ Agua limpia → Tanque
```

**Construcción DIY First Flush:**
- Tubo PVC 4" × 60cm altura
- Válvula flotante arriba
- Válvula drenaje abajo
- **Costo**: $8,000-$15,000 CLP
- **Función**: Descarta primeros 20L (más sucios)

**Filtro de Hojas**:
- Malla acero inoxidable
- 1-2mm apertura
- Instalado en cada bajada
- Limpieza: mensual en otoño

#### 4. Almacenamiento (Tanques)

**Opciones de Tanques**:

| Tipo | Capacidad | Costo | Ventajas | Desventajas |
|------|-----------|-------|----------|-------------|
| IBC (cubo plástico) | 1,000 L | $45,000 | Modular, fácil instalar | Feo, UV lo degrada |
| Tanque polietileno | 500-10,000 L | $80-$450/L | Durable, muchos tamaños | Puede crecer algas |
| Estanque ferrocemento | 5,000-50,000 L | $150-$300/L | Hermoso, permanente | Construcción lenta |
| Cisterna subterránea | 10,000-100,000 L | $400-$700/L | No ocupa espacio, fresco | Caro, necesita bomba |
| Estanque prefabricado | 2,000-20,000 L | $200-$400/L | Rápido instalar | Transporte complejo |

**Cálculo de Tamaño de Tanque Necesario**:

```
Método del "período seco máximo":

Ejemplo Región Metropolitana:
- Llueve: Abril-Septiembre (6 meses)
- No llueve: Octubre-Marzo (6 meses)

Consumo familia (uso consciente):
- 4 personas × 50 L/día × 180 días secos = 36,000 L

Captación en temporada lluvia:
- 100m² techo × 600mm × 0.9 = 54,000 L

Tanque recomendado: 10,000-15,000 L
(No necesitas almacenar todo - haces 3-4 "tandas")
```

## Tratamiento de Aguas Grises

### Introducción

**Aguas grises** son aguas usadas provenientes de:
- ✅ Ducha y tina
- ✅ Lavamanos
- ✅ Lavadora (excepto pañales)
- ✅ Cocina (con filtro trampa grasa)

**NO son aguas grises (son negras)**:
- ❌ WC / inodoro
- ❌ Lavavajillas con restos comida

**Volumen**: 50-70% del agua total de una casa

### ¿Por Qué Tratar Aguas Grises?

1. **Ahorro de Agua**: Reutilizar 100-150 L/persona/día
2. **Reducir Carga Séptica**: -60% carga en fosa séptica
3. **Riego Gratis**: Nutriente natural (nitrógeno, fósforo)
4. **Regeneración**: Crear zonas verdes en lugares secos
5. **Autonomía**: Menos dependencia de infraestructura

**Regulación Chile**: Decreto 1290/2004 permite reutilización para riego con tratamiento básico

### Tipos de Sistemas de Tratamiento

#### 1. Sistema de Infiltración Simple (Mulch Basin)

**Descripción**: Agua gris va directamente a un pozo de infiltración con materia orgánica.

```
Vista corte:
         Desde casa
             │
             ↓
    ┌────────────────┐
    │ Mulch (paja,   │ ← 50-80cm profundidad
    │ viruta, chips) │
    │                │
    └────────────────┘
    ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  ← Suelo natural

Plantas alrededor consumen agua
```

**Ideal para**:
- Casas rurales
- Volumen bajo (<200 L/día)
- Suelo permeable

**Costo**: $80,000-$180,000 CLP  
**Mantenimiento**: Agregar mulch 2 veces/año

#### 2. Branched Drain (Sistema Ramificado)

**Descripción**: Tubería enterrada que distribuye agua gris a múltiples puntos de descarga.

```
Vista superior:
        Casa
         │
    ┌────┴────┐
    │    │    │
   1:1   1:1  1:1  ← Divisiones simétricas
    │    │    │
   🌳   🌳  🌳   ← Árboles frutales
```

**Ventajas**:
- Sin electricidad ni bombas
- Riego directo a raíces
- Bajo mantención

**Ideal para**:
- Terrenos con pendiente natural
- Riego de árboles frutales
- 200-600 L/día

**Costo**: $250,000-$500,000 CLP  
**Instalación**: 2-3 días (DIY posible)

#### 3. Jardín Filtrante (Constructed Wetland)

**Descripción**: Estanque poco profundo con plantas acuáticas que filtran agua biológicamente.

```
Vista corte:

 Agua gris →  [Zona 1]  [Zona 2]  [Zona 3]  → Agua limpia
              Juncos    Papiros   Nenúfares
              ╱╲╱╲╱╲   ╱╲╱╲╱     ╱╲╱╲
             ▓▓▓▓▓▓▓   ▓▓▓▓▓▓▓    ▓▓▓▓▓
             Grava     Arena      Grava
             gruesa    fina       fina
```

**Dimensionamiento**:
- 1 m² de jardín filtrante por cada 50-60 L/día
- Familia 4 personas (300 L/día) → 5-6 m² jardín

**Plantas Recomendadas (Chile)**:

**Ventajas**:

- Bajo costo operación
- Crea hábitat fauna

**Costo**: $800,000-$1,800,000 CLP (5m²)  
**Tiempo construcción**: 5-7 días

#### 4. Sistema con Filtro Biológico Empacado

**Descripción**: Tanque con medios filtrantes (piedra volcánica, gravilla) donde colonias bacterianas tratan agua.

## Estanques y Lagos Naturales

### Introducción

Los **estanques naturales** son cuerpos de agua diseñados para:
1. Almacenar agua (riego, emergencias)
2. Crear microclima (modera temperatura)
3. Biodiversidad (anfibios, insectos benéficos, aves)
4. Producción (peces, plantas acuáticas)
5. Belleza y recreación

### Ubicación Óptima

**Reglas de Ubicación**:
1. **En punto bajo del terreno** (agua fluye naturalmente)
2. **Donde convergen curvas de nivel** (valle natural)
3. **Abajo de swales** (alimentación constante)
4. **Orientación norte** (máximo sol en hemisferio sur)
5. **Lejos de árboles grandes** (raíces perforan impermeabilización)
6. **Visible desde casa** (disfrute + seguridad niños)

### Diseño y Dimensionamiento

#### Tamaños Típicos

**Estanque Pequeño** (Patio/Jardín):
- Superficie: 10-30 m²
- Profundidad: 80-120 cm
- Volumen: 10-25 m³
- Función: Ornamental + riego
- Costo: $450,000-$900,000 CLP

**Estanque Mediano** (Producción):
- Superficie: 50-150 m²
- Profundidad: 120-180 cm
- Volumen: 80-200 m³
- Función: Riego + peces + microclima
- Costo: $1,800,000-$4,500,000 CLP

**Estanque Grande** (Reservorio):
- Superficie: 200-1000 m²
- Profundidad: 180-250 cm
- Volumen: 400-2000 m³
- Función: Reserva estratégica agua
- Costo: $6,000,000-$25,000,000 CLP

#### Forma del Estanque

**Forma Natural (Riñón/Óvalo)**:
```
       ╭─────────╮
      ╱           ╲
     │   Profundo  │  ← Centro profundo
     │    ●        │
      ╲   Orillas /   ← Orillas suaves
       ╰─────────╯
```

**Ventajas**:
- Estético y natural
- Zonas diversas (profundo/somero)
- Mejor para biodiversidad

**Forma Eficiente (Circular/Cuadrada)**:
```
    ┌─────────────┐
    │             │
    │      ●      │  ← Máximo volumen
    │             │  ← Mínima superficie
    └─────────────┘
```

**Ventajas**:
- Menos excavación
- Más volumen por m² superficie
- Más fácil cubrir (evitar evaporación)

#### Profundidad por Zonas

```
Vista corte estanque completo:

Orilla    Somero  Medio    Profundo
  │        │       │          │
  ▼        ▼       ▼          ▼
  ┊  ┊──┬──┬───┬───┬──────────┐
 10cm│30│60 │120│    180cm    │
     └───┴───┴────────────────┘

Zona 1 (0-10cm): Plantas orilla
Zona 2 (30-60cm): Plantas palustres
Zona 3 (60-120cm): Oxigenadoras
Zona 4 (120-180cm+): Peces, reserva agua
```

### Impermeabilización

#### Opción 1: Arcilla Compactada (Tradicional)

**Método**:
1. Excavar estanque con taludes suaves (1:3)
2. Agregar capa arcilla 20-30cm
3. Compactar con pisón o rodillo vibratorio
4. Agregar segunda capa arcilla 20cm
5. Compactar nuevamente
6. Llenar lentamente

**Ideal si**:
- Tienes arcilla en tu terreno (gratis)
- No hay apuro
- Quieres máxima naturalidad

**Costo**: $150-$300/m² (solo mano de obra si hay arcilla local)  
**Tiempo**: 2-3 semanas (incluye secado entre capas)  
**Desventaja**: Puede perder agua si arcilla se agrieta

#### Opción 2: Geomembrana HDPE

**Método**:
1. Excavar y alisar fondo/taludes
2. Colocar geotextil (protección)
3. Extender geomembrana HDPE (0.5-1mm grosor)
4. Soldar traslapes con calor
5. Cubrir bordes con tierra/piedra

**Ideal si**:
- Necesitas garantía impermeabilidad
- Suelo es muy permeable (arena/grava)
- Quieres rapidez

**Costo**: $4,500-$7,000/m² instalada  
**Tiempo**: 3-5 días  
**Vida útil**: 20-30 años

#### Opción 3: Bentonita (Arcilla Expandente)

**Método**:
1. Excavar estanque
2. Esparcir bentonita en polvo (5-8 kg/m²)
3. Mezclar con primeros 10cm de suelo
4. Compactar
5. Llenar agua (bentonita expande y sella)

**Ideal si**:
- Suelo tiene algo de arcilla
- Quieres solución intermedia
- Presupuesto medio

**Costo**: $800-$1,500/m²  
**Ventaja**: Natural, auto-reparable  
**Desventaja**: No funciona en suelo muy arenoso

### Alimentación del Estanque

#### 1. Aguas de Lluvia (Techo)
- Canaletas → Estanque
- Pre-filtro esencial
- Aporta 60-80% del agua

#### 2. Swales
- Rebose de swales → Estanque
- Agua ya filtrada por suelo
- Aporta 20-30%

#### 3. Aguas Grises Tratadas
- Jardín filtrante → Estanque
- Solo si tratamiento completo
- Aporta 10-20%

#### 4. Escorrentía Superficial
- Canalizar agua de cerro
- Necesita desarenador (trampa sedimentos)
- Puede traer erosión

### Plantación del Estanque

#### Plantas por Zona

**Zona 1: Orilla (0-10cm agua)**
- Junco florido (Butomus)
- Iris de agua
- Menta de agua
- Berro

**Zona 2: Palustre (10-60cm)**
- Totora (Typha)
- Papiro (Cyperus)
- Sagitaria
- Lirio amarillo

**Zona 3: Flotantes (60-120cm)**
- Nenúfar (Nymphaea)
- Loto (Nelumbo)
- Jacinto de agua (control: puede invadir)

**Zona 4: Oxigenadoras (sumergidas)**
- Elodea
- Vallisneria
- Ceratophyllum
- Myriophyllum

**Función**: Producen oxígeno, evitan algas, clarifican agua

### Fauna del Estanque

#### Peces (Opcional)

**Carpas Koi/Comunes**:
- Ornamentales
- Comen larvas mosquitos
- Necesitan 60cm+ profundidad invierno
- Densidad: 1 pez por cada 1000 litros

**Truchas** (solo agua fría <18°C):
- Comestibles
- Necesitan agua oxigenada
- Más exigentes

**Peces Nativos (recomendado)**:
- Cauque
- Pejerrey chileno
- Se adaptan mejor al clima

#### Anfibios (Llegan solos)
- Ranas chilenas
- Sapos de rulo
- Esenciales para control plagas

#### Insectos Benéficos
- Libélulas (larvas comen mosquitos)
- Escarabajos acuáticos
- Zapateros

### Mantenimiento

**Primavera**:
- Limpiar hojas acumuladas en fondo
- Dividir plantas que crecieron mucho
- Verificar nivel agua

**Verano**:
- Rellenar agua evaporada (10-20mm/día)
- Controlar algas (agregar plantas si hay muchas)
- Cosechar plantas excedentes (compost)

**Otoño**:
- Colocar red si hay árboles cerca (atrapar hojas)
- Reducir alimentación peces

**Invierno**:
- Mantener zona sin hielo (si hiela)
- Dejar morir plantas anuales
- Mínima intervención

## Diseño de Permacultura Integral

### Principios Fundamentales

La permacultura es un sistema de diseño basado en:

1. **Observar e Interactuar**: Conocer el sitio antes de actuar
2. **Capturar y Almacenar Energía**: Sol, agua, nutrientes
3. **Obtener un Rendimiento**: Producción desde año 1
4. **Autorregulación y Retroalimentación**: Sistemas autocorregibles
5. **Usar Recursos Renovables**: Sol, lluvia, viento
6. **No Producir Residuos**: Todo es recurso
7. **Diseñar desde Patrones a Detalles**: Ver el todo antes que partes
8. **Integrar en Vez de Segregar**: Elementos se apoyan mutuamente
9. **Soluciones Lentas y Pequeñas**: Paso a paso
10. **Valorar la Diversidad**: Más especies = más resiliencia
11. **Usar los Bordes**: Transiciones son productivas
12. **Responder Creativamente al Cambio**: Adaptabilidad

### Las 5 Zonas de Permacultura

```
Vista aérea terreno:

    🌲🌲🌲🌲🌲  Zona 5 (Bosque nativo)
   🌳🌳🌳🌳🌳   Zona 4 (Bosque alimentario)
  🌿🐔🌿🌿🌿    Zona 3 (Animales, frutales)
 🥬🍅🥕🥬🌶️     Zona 2 (Huerto intensivo)
  🏠🪴🪴        Zona 1 (Casa + hierbas)
```

**Zona 0**: La casa/vivienda
- Centro del diseño
- Máxima eficiencia energética
- Captación solar, agua

**Zona 1**: Inmediato a la casa (0-10m)
- Hierbas de uso diario (albahaca, menta)
- Lechugas y aromáticas
- Visitas diarias
- Riego por goteo o manual fácil

**Zona 2**: Huerto principal (10-50m)
- Verduras y hortalizas
- Invernadero
- Compost
- Visitas 2-3 veces/semana

**Zona 3**: Cultivos extensivos (50-150m)
- Árboles frutales
- Animales (gallinas, abejas)
- Forraje
- Visitas semanales

**Zona 4**: Semi-silvestre (150m+)
- Bosque alimentario
- Recolección (frutos silvestres)
- Madera
- Visitas mensuales

**Zona 5**: Naturaleza salvaje
- Sin intervención humana
- Observación y aprendizaje
- Conservación biodiversidad

### Elementos de un Diseño Permacultural Completo

#### 1. Casa Bioclimática
- Orientación solar (norte en Chile)
- Masa térmica
- Ventilación cruzada
- Construcción natural

#### 2. Agua (70% del diseño)
- Levantamiento topográfico
- Swales en curvas de nivel
- Cosecha agua techos → Tanques
- Aguas grises → Jardín filtrante
- Estanques en puntos bajos
- Pozos de infiltración

#### 3. Suelos
- Análisis de suelo inicial
- Compostaje descentralizado
- Mulching permanente
- Cultivos de cobertura
- Rotación y policultivos

#### 4. Bosque Alimentario
- Estratos: árboles, arbustos, herbáceas, raíces, trepadoras, cubiertas
- Fijadores de nitrógeno (leguminosas)
- Polinizadores (flores)
- Control natural plagas

#### 5. Animales Integrados
- Gallinas: control plagas, fertilización, huevos
- Abejas: polinización, miel
- Patos: control babosas en huerto húmedo
- Cada animal cumple 3+ funciones

#### 6. Energía
- Solar fotovoltaica (electricidad)
- Solar térmica (agua caliente)
- Rocket mass heater (calefacción)
- Biodigestro (gas desde estiércol)

#### 7. Estructuras Especiales
- Invernadero (producción invierno)
- Walipini (invernadero subterráneo)
- Baño seco (cerrar ciclo nutrientes)
- Horno de barro (comunitario)

### Proceso de Diseño (12 pasos)

**Mes 1-2: Observación**
1. Caminar el terreno en diferentes momentos del día
2. Anotar: recorrido sol, vientos, agua (¿dónde se acumula?)
3. Hacer mapa base (límites, construcciones existentes, caminos)
4. Análisis de suelo (3-5 muestras)
5. Registro fotográfico (4 estaciones si es posible)

**Mes 3: Análisis**
6. Identificar recursos (agua, sol, tierra fértil, árboles útiles)
7. Identificar problemas (erosión, zonas anegadas, heladas)
8. Definir prioridades (¿agua primero?, ¿suelo?, ¿protección viento?)

**Mes 4-5: Diseño en Papel**
9. Dibujar mapa de curvas de nivel
10. Ubicar elementos por zona (casa → bosque)
11. Diseñar flujos de agua (swales, tanques, estanques)
12. Planificar fases de implementación (5-10 años)

**Año 1+: Implementación por Fases**

**Fase 1 (Año 1): Agua y Accesos**
- Levantamiento topográfico profesional
- Construir swales principales
- Tanques de agua de lluvia
- Caminos de acceso (siguiendo contorno)
- **Inversión**: 30-40% del presupuesto total

**Fase 2 (Año 1-2): Estructuras y Suelo**

- Composteras y preparación suelo
- Zona 1 y 2 (hierbas y huerto)
- Cercos y divisiones
- **Inversión**: 40-50% del presupuesto

**Fase 3 (Año 2-3): Plantación Permanente**
- Árboles frutales (zona 3)
- Bosque alimentario (zona 4)
- Cercos vivos
- Plantas bermas de swales
- **Inversión**: 10-15% del presupuesto

**Fase 4 (Año 3-5): Afinamiento**
- Aguas grises tratadas
- Estanques (si aún no)

- Energías renovables
- **Inversión**: 5-10% del presupuesto

## Integración de Sistemas

### El Poder de la Integración

En permacultura, **cada elemento cumple múltiples funciones** y **cada función es soportada por múltiples elementos**.

#### Ejemplo: El Estanque Multifuncional

Un estanque bien diseñado cumple:

1. **Almacenamiento**: 50,000 L agua para riego seco
2. **Microclima**: Modera temperatura ±3-5°C en 30m radio
3. **Biodiversidad**: Anfibios comen plagas del huerto
4. **Producción**: 120 kg peces/año
5. **Belleza**: Aumenta valor propiedad 15-25%
6. **Refugio**: Fauna en incendios forestales
7. **Riego pasivo**: Evaporación riega árboles cercanos
8. **Reflejo luz**: +10% luz a invernadero norte del estanque

#### Ejemplo: Gallinas en el Sistema

Gallinas integradas cumplen:

1. **Control plagas**: Comen larvas, babosas, caracoles
2. **Fertilización**: Estiércol de alto nitrógeno
3. **Preparación suelo**: Rascan y airean (tractores con plumas)
4. **Producción**: 250 huevos/año/gallina
5. **Control malezas**: Comen semillas indeseables
6. **Reciclaje**: Convierten restos cocina en huevos
7. **Alarma**: Avisan presencia de zorros/depredadores
8. **Compañía**: Elemento vivo educativo para niños

### Diseños de Integración Clásicos

#### Sistema 1: "Huerto-Gallinas-Compost"

```
Rotación trimestral:

Trimestre 1:  [HUERTO] → [GALLINAS] → [COMPOST]
              Produce   Limpian     Madura
                ↓          ↓            ↓
Trimestre 2:  [COMPOST] → [HUERTO] → [GALLINAS]
              Abono      Produce    Limpian
                ↓          ↓            ↓
Trimestre 3:  [GALLINAS] → [COMPOST] → [HUERTO]
              Preparan   Madura      Produce

Cada sector rota funciones. Sistema autofertilizante.
```

**Resultado**: 
- Cero necesidad de fertilizantes externos
- Control plagas sin químicos
- Suelo mejora 300% en 2 años

#### Sistema 2: "Swale-Berma-Árbol-Ganso"

```
Vista corte:

Cerro →  Swale  Berma  Árbol Frutal
         ═════  ╱╲     🌳
Agua lluvia →  🦆    └─ Raíces beben del swale
               Gansos bajo árbol:
               - Comen pasto (no necesitan cortar)
               - Fertilizan árbol
               - No dañan fruta (no saltan alto)
```

#### Sistema 3: "Casa-Invernadero-Gallinero" (Invierno)

```
Vista lateral (flujos de calor):

         ☀️ Sol invernal
          ↓
    [Invernadero] → Aire caliente → [Casa]
          ↑                            ↓
    Calor aves ← [Gallinero] ←─ Aire tibio

Día: Invernadero calienta casa
Noche: Gallinero calienta invernadero (gallinas = 10W calor c/u)
```

**Resultado invierno**: 
- Casa: +5°C vs. exterior
- Invernadero: +8-12°C vs. exterior
- Cero calefacción artificial

5. **Implementar por etapas**: No todo el primer año
6. **Aprender haciendo**: Cada terreno es único
7. **Conectar con comunidad**: Buscar permacultores locales
8. **Documentar**: Fotos antes/después son poderosas

# EcoArq - Plataforma de Diseño de Construcción Natural 🏡

Una aplicación web integral para diseñar, planificar y calcular proyectos de construcción natural y sostenible.

## 🌟 Características

### 1. Calculadora de Materiales
Calcula con precisión los materiales necesarios para tu proyecto según 11 técnicas constructivas:
- **Adobe**: Bloques de tierra, arena y paja
- **Cob**: Construcción monolítica de tierra
- **Superadobe**: Sacos rellenos de tierra
- **Bahareque/Quincha**: Entramado de caña con tierra
- **Pacas de Paja**: Construcción con fardos
- **Bambú**: Estructuras de caña de bambú
- **Piedra**: Construcción tradicional de piedra
- **Botellas de Vidrio**: Muros con botellas recicladas
- **Tapia/Tapial**: Tierra compactada
- **Tierra-Paja**: Mezcla ligera aislante
- **Madera**: Construcción de madera natural

### 2. Guía de Técnicas Constructivas
Información completa sobre cada técnica:
- Descripción detallada
- Ventajas y desventajas
- Aplicaciones ideales según clima
- Proceso de construcción paso a paso

### 3. Planificador de Proyectos
Genera planes detallados para tu proyecto:
- Fases de construcción
- Cronograma estimado
- Distribución de presupuesto
- Lista de tareas por fase
- Consejos específicos por técnica

### 4. Inspiración y Diseños
Ejemplos de proyectos reales:
- Diferentes técnicas constructivas
- Adaptaciones climáticas
- Principios de diseño sostenible
- Estrategias bioclimáticas

### 5. Visualización 3D y Planos
Herramientas para llevar tu proyecto al siguiente nivel:
- **Exportación de datos**: JSON y TXT con especificaciones técnicas
- **Guías de software**: 6 programas 3D (gratuitos y de pago)
- **Proceso de renderizado**: 6 pasos detallados
- **Recursos**: Tutoriales, texturas, comunidades
- **Casos de estudio**: Ejemplos reales de proyectos renderizados

## 🚀 Instalación y Uso

### Prerrequisitos
- Node.js (versión 16 o superior)
- npm o yarn

### Instalación

1. Clona el repositorio:
```bash
git clone <tu-repositorio>
cd <nombre-repositorio>
```

2. Instala las dependencias del frontend:
```bash
cd frontend
npm install
```

3. Inicia la aplicación:
```bash
npm start
```

La aplicación se abrirá en [http://localhost:3000](http://localhost:3000)

### Build para Producción

```bash
npm run build
```

Esto creará una versión optimizada en la carpeta `build/`.

## 🌍 Técnicas de Construcción Natural Soportadas

### Adobe
Bloques de tierra cruda ideal para climas secos. Excelente inercia térmica y durabilidad centenaria.

### Cob
Construcción monolítica que permite formas orgánicas. Ideal para autoconstrucción y diseños creativos.

### Superadobe
Sacos de tierra en forma de domo. Muy resistente a sismos y huracanes.

### Bahareque (Quincha)
Entramado liviano de caña o bambú. Flexible, rápido y ideal para zonas tropicales.

### Pacas de Paja
Excelente aislamiento térmico. Ideal para climas fríos y construcciones eficientes.

### Bambú
Material renovable más resistente que el acero. Perfecto para estructuras livianas.

### Piedra
Construcción tradicional con piedra natural. Durabilidad excepcional de siglos y excelente masa térmica.

### Botellas de Vidrio Recicladas
Muros creativos con botellas que crean efectos lumínicos únicos. Reutiliza residuos y aporta valor artístico.

### Tapia/Tapial (Tierra Compactada)
Tierra compactada entre encofrados. Muros monolíticos muy resistentes con acabado contemporáneo.

### Tierra-Paja (Light Earth)
Mezcla ligera de paja con barbotina de arcilla. Excelente aislamiento térmico y transpirabilidad.

### Madera
Construcción tradicional con madera natural certificada. Material renovable con estética cálida.

## 📊 Cálculos y Estimaciones

La aplicación proporciona:
- Cantidades de materiales por m²
- Estimaciones de costos en CLP
- Ajustes según espesor y altura de muros
- Recomendaciones de seguridad (10-15% extra)

**Nota**: Los cálculos son aproximados y deben ser verificados con profesionales locales.

## 🌱 Beneficios de la Construcción Natural

### Ambientales
- Reducción de huella de carbono
- Materiales renovables y locales
- Mínimo procesamiento industrial
- Biodegradable

### Económicos
- Reducción de costos (hasta 50%)
- Materiales de bajo costo o gratuitos
- Fomenta autoconstrucción

### Sociales
- Fortalece comunidades
- Recupera técnicas tradicionales
- Empodera a las personas

### Salud
- Excelente confort térmico
- Regulación natural de humedad
- Materiales no tóxicos
- Ambientes saludables
